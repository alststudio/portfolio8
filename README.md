# KV Freight Group — Halaman Perusahaan

Situs satu halaman (single-file) untuk perusahaan fiktif **KV Freight Group** — grup pengiriman barang dan logistik internasional. Seluruh tampilan berbahasa Indonesia.

## Isi

- **Hero sinematik** — animasi reach-stacker & truk yang dikendalikan guliran (video scrubbing) dengan tipografi raksasa "Layanan Kami", indikator kecepatan, dan strip layanan.
- **12 bagian lengkap** — Layanan, Tentang KV, Jaringan Global (peta dunia SVG konseptual), Mengapa KV, Kapabilitas, Cara Kerja, Industri, Showcase, CTA, Kontak, dan Footer.
- **Formulir kontak demo** — validasi sisi klien lengkap; belum terhubung ke server (titik integrasi ditandai jelas di dalam kode).

## Teknologi

Satu file `docs/index.html` berisi seluruh HTML, CSS, dan JavaScript vanilla — tanpa framework dan tanpa proses build. Font: Anton, Archivo, dan JetBrains Mono (Google Fonts). Foto pendukung dari Unsplash; video hero dari aset CloudFront pada brief.

## Catatan kejujuran konten

Perusahaan ini fiktif. Statistik ditampilkan sebagai nilai kualitatif ilustratif, peta adalah visualisasi konseptual, dan detail kontak adalah placeholder yang ditandai jelas (domain `.example`).

## Menjalankan

Buka `docs/index.html` di peramban modern, atau sajikan folder `docs/` dengan server statis apa pun. Situs diterbitkan melalui GitHub Pages dari folder `/docs` di branch `main`.
